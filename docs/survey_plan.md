# Check · 1분 부모님 건강기록 관리 습관 유형 체크 & 수요조사 기획서 (1라운드 심사 기준 및 중립성 반영 최종본)

## 1. 설문 6문항 및 선택지 전문 (단점 단정 제거 및 중립적 설명 적용)

### Q1. 부모님 건강관리 경험
- **상단 안내문**: 부모님의 외래 진료에 동행하거나 복약 기록을 챙기던 순간 중 '가장 기억에 남는 경험' 하나를 골라주세요.
- **질문**: 최근 1년 동안 부모님의 병원 방문이나 약 관리를 도우면서 어떤 경험이 있으셨나요?
- **선택지**:
  1. `💦 진료 중 바로 답하기 어려웠어요` / 복용약이나 증상이 시작된 시점을 물어본 경험 (`exp_hard_answer`)
  2. `💬 물어볼 질문을 잊어버렸어요` / 진료가 끝난 뒤 질문이 떠오른 경험 (`exp_forgot_question`)
  3. `💊 여러 약을 확인해야 했어요` / 서로 다른 병원의 처방약이나 영양제를 확인한 경험 (`exp_multi_meds`)
  4. `✨ 별다른 불편이 없었어요` / 필요한 정보를 확인하고 진료를 마친 경험 (`exp_no_issue`)
  5. `🌱 아직 직접 도운 경험이 없어요` / 앞으로 부모님 건강관리를 도울 가능성이 있는 경우 (`exp_none_yet`)

### Q2. 건강기록 보관 방법
- **질문**: 부모님의 약봉투, 증상 사진, 병원 일정은 평소 어디에 기록하거나 보관하시나요?
- **선택지**:
  1. `📱 스마트폰 사진첩` / 약봉투나 병원 관련 자료를 사진으로 저장해요 (`store_album`)
  2. `💬 가족 카카오톡·문자` / 가족과 사진이나 메시지로 주고받아요 (`store_kakao`)
  3. `📓 캘린더·메모장·수첩` / 날짜와 내용을 직접 적어둬요 (`store_memo`)
  4. `🗂️ 전용 기록 앱·폴더` / 건강 관련 정보를 한곳에 모아둬요 (`store_app_folder`)
  5. `🧠 별도로 기록하지 않아요` / 필요할 때 기억하거나 가족에게 확인해요 (`store_none`)

### Q3. 과거 기록 재확인 경험
- **질문**: 부모님의 이전 복용약이나 증상 기록을 다시 확인할 때, 어떤 경험이 있으셨나요?
- **선택지**:
  1. `🔎 기록을 다시 찾아야 했어요` / 사진, 메시지, 서류 등을 찾아본 경험 (`recheck_search`)
  2. `📝 약 이름을 정리해야 했어요` / 여러 약의 이름이나 복용 정보를 모아본 경험 (`recheck_med_list`)
  3. `🗓️ 증상 발생 시점을 확인해야 했어요` / 언제 증상이 있었는지 날짜를 확인한 경험 (`recheck_symptom_date`)
  4. `✅ 필요한 기록을 쉽게 확인했어요` / 평소 관리하던 기록을 바로 확인한 경험 (`recheck_easy`)
  5. `🌱 다시 확인할 일이 없었어요` / 이전 기록을 찾아본 경험이 없는 경우 (`recheck_none`)

### Q4. 가족 간 건강정보 소통 및 공유 범위
- **질문**: 부모님의 건강정보를 가족과 주고받거나 공유할 때 어떤 방식을 선호하시거나 경험하셨나요?
- **선택지**:
  1. `💬 가족 전체 단톡방에서 공유해요` / 모든 가족 구성원에게 사진이나 메시지를 전달한 경험 (`share_group_chat`)
  2. `🔒 필요한 가족만 선택해 따로 소통해요` / 원하는 가족만 초대하거나 일부에게만 정보를 전달한 경험 (`share_selected_family`)
  3. `📋 병원 방문 전후로 필요한 기록만 공유해요` / 평소엔 각자 관리하고 진료 시점에만 요약 정보를 전달 (`share_visit_summary`)
  4. `🤝 부모님 사전 동의 후 허용된 항목만 공유해요` / 민감한 정보는 가리고 동의된 범위만 가족과 공유 (`share_parent_consent`)
  5. `🌿 공유한 경험이 없어요` / 가족과 건강정보를 주고받지 않은 경우 (`share_none_exp`)

### Q5. 가장 필요한 기능 1순위
- **질문**: 부모님의 건강기록을 관리할 때, 가장 도움이 될 것 같은 기능 하나를 골라주세요.
- **선택지**:
  1. `📅 날짜별 건강 달력` / 증상 메모, 사진, 병원 일정을 날짜별로 기록 (`feat_calendar`)
  2. `💊 복용약·처방전 정리` / 약봉투와 처방전 내용을 목록으로 정리 (`feat_med_list`)
  3. `📋 병원 방문 준비 카드` / 최근 기록과 질문을 한 장으로 정리 (`feat_visit_card`)
  4. `🔐 가족별 선택적 공유·소통` / 초대한 가족에게만 필요한 기록을 공유하고 소통 (`feat_selective_share`)
  5. `🌿 지금 방식으로 충분해요` / 별도의 기능이 필요하지 않은 경우 (`feat_current_enough`)

### Q6. 실제 문제의 반복 빈도 (재사용성 검증)
- **질문**: 최근 6개월 동안 부모님의 건강정보를 다시 찾거나 가족에게 확인해야 했던 일이 얼마나 자주 있었나요?
- **선택지**:
  1. `🔄 5번 이상 있었어요` / 병원 방문이나 약 확인 때마다 자주 찾아본 경우 (`freq_5_plus`)
  2. `📅 3~4번 있었어요` / 분기나 격월 단위로 기록을 다시 확인한 경우 (`freq_3_4`)
  3. `🔎 1~2번 있었어요` / 가끔 필요할 때 이전 기록을 찾아본 경우 (`freq_1_2`)
  4. `✨ 한 번도 없었어요` / 최근 6개월 내 다시 찾아볼 일이 없었던 경우 (`freq_zero`)
  5. `🌱 최근 6개월 동안 부모님 건강관리를 도운 적이 없어요` / 해당 기간 내 관련 경험이 없는 경우 (`freq_no_help`)

## 2. 결과 유형 중립화 및 매칭 로직 (점수 서열화 배제)
- 의학적 진단이나 실제 건강관리 능력을 평가한 결과가 아님을 명확히 안내하며, Q1~Q4의 보관·확인·소통 방식을 바탕으로 4가지 기록 습관 유형을 중립적으로 안내합니다.
  1. **🌷 유형 1. 마음만은 든든, 기억·대화 중심 확인형**
  2. **🔍 유형 2. 사진첩·단톡방 스크롤 탐정형**
  3. **📓 유형 3. 수첩·메모장 꼼꼼 기록 매니저형**
  4. **🏆 유형 4. 체계적인 스마트 동행 기록 프로형**

## 3. 선택형 1줄 자유응답(VOC) 익명 수집
- **질문**: "부모님의 건강정보를 챙기면서 기억에 남는 불편한 경험이 있나요? (선택사항)"
- **안내 문구**: "있다면 짧게 들려주세요. 병명, 실명, 상세 처방 내용 등 민감한 개인정보는 적지 말아주세요."
- **저장 구조**: 연락처 입력 없이 익명 설문 응답 데이터(`data/responses.json`)의 `vocComment` 필드에 저장되어 관리자 대시보드(`/admin`) 및 CSV 다운로드에서 즉시 확인 가능.
